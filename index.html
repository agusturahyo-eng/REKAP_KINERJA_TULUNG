📱 1. Sinkronisasi PLN Mobile (Langsung Filter Server dari Master Responses)

Menyaring otomatis khusus data ULP Tulung pada Bulan & Tahun Aktif langsung dari server Google Sheet (Master Responses), memvalidasi Check-Digit 12 angka IDPEL, dan menandai data ganda.

📄 2A. Upload Manual Laporan PDF PDIL Bulanan (Mesin PDF Turbo — Tetap Aktif)

Menggunakan algoritma PDF Turbo (Koordinat Baris Y Top-Down) sehingga seluruh ratusan baris petugas di setiap halaman masuk 100% tanpa terpotong pergantian halaman, mengambil KdBaca huruf (Z, dll) secara presisi, serta mengisi Koked (KDRBM+Langkah+Sisipan) murni dari PDF!

⚡ 2B. Tarik Data PDIL Langsung dari Server ACMT (fisikmeterlpb) — Anti-Timeout PDF!

Solusi saat download PDF di ACMT gagal/timeout karena data terlalu banyak. Silakan pilih: (Cara 1 - Paling Aman) Klik Bookmark di tab ACMT untuk mengunduh file .json lalu upload di bawah, atau (Cara 2) Paste Copy as fetch / Token Bearer ACMT untuk menarik langsung dari halaman ini.

📂 Opsi 1 (Rekomendasi Aman): Upload File JSON / Excel dari Bookmark ACMT:
Cara Pasang Bookmark 1-Klik di Chrome (Cukup Sekali Saja):
  1. Klik tombol "📋 Copy Kode Bookmark" di bawah, lalu buat Bookmark baru di Chrome (klik kanan di Bar Bookmark Chrome → Add page / Tambahkan halaman).
  2. Beri nama "⬇️ Tarik PDIL ACMT", dan pada kolom URL tempelkan (Paste) kode yang sudah disalin.
  3. Saat membuka halaman Monitoring Fisik Meter MPB di ACMT, cukup klik Bookmark tersebut (atau Paste kodenya di Console F12). Skrip otomatis mengambil token login aktif, menarik seluruh halaman secara aman, lalu mengunduh file PDIL_ACMT_52405.json!
